# 東京五人行

2026/10/03 – 10/09 東京六日遊的行程、花費與分帳紀錄。

## 打開方式

純靜態網頁,沒有任何後端或建置步驟。

- 直接用瀏覽器開 `index.html`
- 或透過 GitHub Pages:`https://aluludesign.github.io/playground/tokyo-trip/`

## 內容

| 分頁 | 做什麼 |
| --- | --- |
| 行程 | Day 1–6 時間軸,航班節點已固定釘上,其餘自行新增 |
| 花費 | 總額、每人平均、分類佔比、逐筆明細(日圓／台幣雙幣別) |
| 分帳 | 每人已付／該付／淨額,以及最少轉帳次數的結清清單 |

## 資料怎麼存

紀錄存在瀏覽器的 localStorage,**只存在你自己的裝置上**。
要跟其他人對帳,用頁尾的「匯出備份」產生 JSON 傳給對方,對方按「匯入備份」讀進去。

- `index.html` — 網站本體(單一檔案,含樣式與邏輯)
- `data/trip.json` — 機票訂單與旅客資料的結構化備份,給人看的,網頁不會讀它
